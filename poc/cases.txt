# PoC capture cases (KI 1, U98 L1.5D). Format:
#   name  function  hit  [capture options...]
# A case stops at the hit-th call of the function that satisfies --when
# (a MAME debugger expression; the caller's return address identifies the
# call site). Plain hit indices are not stable across MAME runs: the game's
# disk write/verify loop does not repeat the same number of times.
# "real" cases capture a call made by the game itself during boot.
# "-interp" cases repeat a real case with MAME's MIPS3 interpreter instead
# of its DRC (two independent MAME CPU back ends).
# "syn" cases (always run with the interpreter, see tools/mame_capture.py)
# stop at a real call and overwrite inputs first; the original
# code still runs inside MAME, but the inputs are synthetic.
